# Nexora Digital

A modern, responsive landing page and digital agency website built with HTML, CSS, and JavaScript.

Nexora Digital is a fictional digital studio created to demonstrate frontend development skills, responsive web design, accessibility, user experience, and basic JavaScript interactivity.

## 📖 About The Project

Nexora Digital is a fictional digital agency that helps businesses create modern digital experiences.

The website was developed as a frontend development project and is designed to demonstrate how a professional multi-page business website can be structured and built using core web technologies.

The website focuses on a clean, modern, dark-themed interface with responsive layouts, smooth animations, interactive navigation, service sections, testimonials, and a contact form.

---

## 🎯 Project Objectives

The main objectives of this project were to:

- Build a professional multi-page website.
- Practice semantic HTML structure.
- Create a responsive layout for desktop, tablet, and mobile devices.
- Use CSS to create a modern visual design.
- Add JavaScript functionality and interactions.
- Implement a responsive mobile navigation menu.
- Add smooth scrolling and reveal animations.
- Create an interactive contact form.
- Organize the project using separate HTML, CSS, and JavaScript files.
- Deploy the website so it can be accessed online.

## ✨ Features

### Responsive Navigation

The website includes a navigation bar with links to:

- Home
- About
- Services
- Contact

On smaller screens, the navigation changes into a mobile hamburger menu.

### Hero Section

The homepage contains a large hero section featuring:

- Main headline
- Supporting description
- Call-to-action buttons
- Business statistics
- Custom dashboard-style visual

### Services

The website presents six services:

1. Web Development
2. Product Design
3. Growth Strategy
4. UI/UX Design
5. Performance
6. Digital Consulting

### About Page

The About page explains:

- Nexora Digital's story
- Company philosophy
- Core values
- Development process

### Testimonials

The homepage includes three fictional client testimonials to demonstrate how customer feedback could be presented on a business website.

### Contact Page

The Contact page contains:

- Email information
- Phone information
- Location
- Contact form
- Service selection
- Project description field

### Animations

JavaScript and CSS are used to create scroll-reveal animations that make content appear smoothly as the user scrolls through the website.

### Responsive Design

The website adapts to:

- Desktop screens
- Tablets
- Mobile phones
